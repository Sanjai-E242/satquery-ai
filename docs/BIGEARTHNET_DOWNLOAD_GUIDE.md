# BigEarthNet Real Satellite Image Patch Download & Acquisition Guide

This guide describes the official, reproducible workflow for acquiring real Sentinel-2 and Sentinel-1 satellite image patches corresponding to the 9.55M question-answer records in `data/BigEarthNet/BigEarthNet.txt.parquet`.

---

## 2. Subset Selection Workflow

To avoid downloading the entire 170 GB archive on local development environments (e.g. MacBook Air), use the automated subset resolution tool to create a manifest CSV:

### Select 100 Patches (Default Development Subset):
```bash
python training/datasets/select_bigearthnet_subset.py --count 100
```

### Scale to 200 or 1,000 Patches:
```bash
# 200 Patches (~23.4 MB)
python training/datasets/select_bigearthnet_subset.py --count 200

# 1,000 Patches (~117.2 MB)
python training/datasets/select_bigearthnet_subset.py --count 1000
```

**Output:** `data/BigEarthNet/subset_manifest.csv` containing selected `patch_id`, `s1_name`, `input`, `output`, `split`, and geospatial metadata.

## 3. Image Acquisition & Dry-Run Execution

Before performing any download, execute a dry run to inspect missing assets, source URLs, and expected disk usage:

### Dry-Run Command:
```bash
python training/datasets/download_bigearthnet_subset.py --count 100 --dry-run
```

### Dry-Run Output Verification:

## 4. Destination Directory Structure

Downloaded real image assets are organized under `data/BigEarthNet/patches/` using the official BigEarthNet naming scheme:

```text
data/BigEarthNet/
├── BigEarthNet.txt.parquet               # (Original Parquet dataset, 445.19 MB)
├── subset_manifest.csv                   # (Manifest generated by select_bigearthnet_subset.py)
└── patches/
    ├── S2A_MSIL2A_20170613T101031_N9999_R022_T33UUP_33_69.png
    ├── S2A_MSIL2A_20170613T101031_N9999_R022_T33UUP_36_52.png
    └── ...
```

## 5. Asset Integrity Verification Commands

After acquiring real image patches, verify asset integrity before starting PyTorch training:

```bash
# 1. Count downloaded image files
ls -1 data/BigEarthNet/patches/*.png | wc -l

# 2. Verify images can be opened by PIL & rasterio
python -c "
from PIL import Image
import glob
files = glob.glob('data/BigEarthNet/patches/*.png')
print(f'Verified {len(files)} image files.')
if files:
    img = Image.open(files[0])
    print('Sample image size:', img.size, 'mode:', img.mode)
"
```
